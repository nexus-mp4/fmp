# fmp
Terminal User Interface music player.

## installation :
### build from source:
dependencies:
- mpv
- ncurses
- ffmpeg
#### Linux:
```bash
git clone https://github.com/nexus-mp4/fmp
cd fmp
sudo make install
```
#### MacOS:
```bash
git clone https://github.com/nexus-mp4/fmp
cd fmp
sudo make install_mac
```
### or execute the precompiled binary:
```bash
git clone https://github.com/nexus-mp4/fmp
.fmp/bin/fmp
```
